Seeing what matters.

AI-Powered CCTV Surveillance and Video Analytics System.

ABOUT THE WORK / 05

From idea to implementation.

Developed an AI-powered CCTV surveillance system using Python, Flask, YOLO, and OpenCV. The project combines object detection and multi-object tracking with event detection and a web-based monitoring workflow.

Key features & contributions

  • Real-time object detection and multi-object tracking using YOLO and ByteTrack.
  • Restricted-zone intrusion detection, line-crossing detection, and loitering detection.
  • Event logging, evidence snapshot capture, and annotated video generation.
  • Web-based monitoring dashboard for video processing, event monitoring, and evidence management.
  • Browser-based sound alerts for HIGH and CRITICAL security events.
