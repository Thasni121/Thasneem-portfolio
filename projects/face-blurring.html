Face Blurring Social Entertainment Platform.

ABOUT THE WORK / 07

From idea to implementation.

Built a privacy-focused social entertainment platform with automatic face blurring using Python, Flask, and OpenCV. It is designed to anonymize faces in uploaded media before sharing or storage.

Key features & contributions

  • Integrated OpenCV DNN and Haar Cascade models for face detection and automatic blurring in uploaded images and videos.
  • Flask backend for file handling, video processing, and secure upload/download functionality.
  • Frontend for media uploads, previews, and blurred-content sharing using HTML, CSS, and JavaScript.
  • Focused on privacy protection by anonymizing faces in media before sharing and storage.
